# Evidence and claim boundary

## Three different claim types

PLTE deliberately separates measured block evidence, a checkpoint distortion projection, and a conditional rate budget.

### 1. Measured on frozen Qwen matrices

The final evidence manifest pins 47 unique selected non-router blocks from the immutable Qwen3-30B-A3B revision:

| Source class | Unique blocks |
|---|---:|
| Embedding matrix | 34 |
| Attention Q/K/V/O | 4 |
| LM head | 2 |
| MoE expert up/down projections | 7 |
| **Total** | **47** |

There are 49 report rows because two normative exemplars duplicate already-counted source blocks. Every report was regenerated by encoder SHA-256 `4d76ba53c88710778085917108b7940517ed14565815fc8437ea4919d7df4bf8`.

Observed results:

- all 47 final containers are at or below 81,242 bytes;
- all observed gaps are below 0.10 dB;
- maximum observed gap: `0.08467495110957093` dB;
- maximum observed container: 81,242 bytes;
- every arithmetic, causal-frequency, frozen-bit, reconstruction-index, scale, tail, padding, and header audit is literal `true`.

The observed coverage is `47 / 116,422 = 0.0403704%` of non-router blocks. This is useful matrix evidence, not a checkpoint-wide maximum.

### 2. Independently decoded evidence

The clean decoder does not import the encoder. It consumes a literal `.polar.bin`, JSON parameters, and the serialized six-mask file. The frozen BF16 source is needed only to audit distortion, not to reconstruct decoded weights.

Eight cases were checked this way:

- the normative expert-up block;
- the heavy-tail embedding block;
- all six controlled expert-down projection blocks.

All eight match the encoder's recorded relative MSE within `1e-12`, and their container and source-block hashes match the pinned manifest.

### 3. Projected checkpoint distortion

The non-router projection uses exactly six adjacent blocks of `model.layers.27.mlp.experts.57.down_proj.weight`. Their recomputed aggregate is:

- source energy: `936.9313635504307`;
- SSE: `30.67438389462925`;
- energy-weighted relative MSE: `0.032739200637270795`.

Their mean energy and SSE are extrapolated across 116,422 non-router blocks, then combined with the exact all-48-router energy and SSE. This produces:

- projected mixed relative MSE: `0.03273955118126599`;
- projected Gaussian gap: `0.08285101917462104` dB.

Only the router term is checkpoint-complete. The mixed number is not a full-checkpoint measurement, and its margin to 0.10 dB is small.

## Router rate-quality alternatives

Using the same non-router projection and replacing only the router format:

| Router format | Conditional global bpw | Projected mixed MSE | Projected gap |
|---|---:|---:|---:|
| All-Q2 | 2.4793092019 | 0.0329189445 | 0.10138779 dB |
| All-Q3 | 2.4797342011 | 0.0327773156 | 0.08522135 dB |
| All-Q4 | 2.4801720791 | 0.0327395512 | 0.08285102 dB |

All-Q3 is Pareto-efficient. All-Q4 is retained because the objective prioritizes minimum distortion while remaining below 2.5 bpw.

## What remains unproven

- 116,375 non-router blocks remain unencoded.
- The 47 blocks are a selected research evidence set, not a statistically unbiased held-out sample; strict PTQ does not remove method-selection or sample-selection bias.
- A slot overflow route is not implemented.
- A whole-checkpoint packer and decoder have not emitted or consumed the stated global format.
- Floating-point probability regeneration must be pinned exactly or replaced by normative fixed-point/LUT arithmetic for portable bit-exact decoding.
- Perplexity and downstream task accuracy have not been evaluated.
- No like-for-like benchmark against published INT2 methods has been completed.
- No exhaustive patent or literature novelty search has been performed.

Accordingly, the release is a preliminary strict-PTQ research candidate, not a definitive SOTA result.
